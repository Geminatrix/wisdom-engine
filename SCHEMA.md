# Wisdom Unit Schema (Canonical)

Every unit is a living, testable, compressible insight. No unit ships without all five fields.

## Structure

```
[WISDOM]
Short distilled insight. One sentence preferred. Max 2.

[WHY IT HOLDS]
Grounding / reasoning. Why this is true across contexts. Cite priors or sources when possible.

[TEST]
Concrete prompt, experiment, or daily check that can falsify or reinforce the unit.

[FAILURE MODE]
How this wisdom breaks, gets misused, or produces harm when applied poorly.

[UPGRADE PATH]
How to deepen, refine, or evolve the unit. What would make the next version stronger.
```

## Source Classes
- **Truth** — falsifiable claims about reality
- **Compression** — packing more signal into less space
- **Grounding** — body, place, nervous system, present moment
- **Sovereignty** — agency, offline capability, least-privilege, Zero Trust
- **Edge** — competitive advantage, skill compounding, attention
- **Care** — care as primary optimization signal, not post-hoc filter
- **Temporal** — longtermism, patience, compounding, time variance

## Rules
1. Every unit must be testable within 24h if desired.
2. Prefer compression over completeness.
3. Tag claims →S / →INF / →PRIOR when used inside agent loops.
4. Free lite ships with this schema + 15 seed units.
5. Paid library targets 50+ units + Pantheon stress-test layer + Notion/sheet templates.
